# Prueba AR.js — Hipogrifo de 7.º grado

Archivos:
- `index.html`: experiencia WebAR.
- `hipogrifo.png`: personaje transparente optimizado.
- `.nojekyll`: evita procesamiento Jekyll en GitHub Pages.

## Publicar con GitHub Pages

1. Crear un repositorio público nuevo en GitHub, por ejemplo `7mo-ar-muestra`.
2. Subir los tres archivos de esta carpeta a la raíz del repositorio.
3. Ir a `Settings` → `Pages`.
4. En `Build and deployment`, elegir `Deploy from a branch`.
5. Branch: `main`; carpeta: `/(root)`; guardar.
6. Abrir la URL que entregue GitHub Pages desde Chrome en la tablet.
7. Aceptar permiso de cámara.
8. Apuntar al marcador HIRO oficial de AR.js.

Esta primera prueba usa un único marcador HIRO. Si funciona en la tablet,
el siguiente paso es sustituirlo por marcadores numerados para los ~20 personajes.
